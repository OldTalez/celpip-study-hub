# Real-device checklist (T-031 turn C)

For the Board. These checks need a real phone or computer, which the automated tests cannot use. Tick each box when it matches "What should happen". If it does not, write what you saw next to it. Test on: iPhone Safari, Android Chrome, desktop Chrome or Edge. Mark a row n/a if the device cannot do it.

Use the online copy of the app (https), not the file on disk: installing and working offline only work from the website.

## 1. Install

**How:** iPhone Safari: Share, then Add to Home Screen. Android Chrome: the Install app button, or menu, Install app. Desktop Chrome/Edge: the install icon in the address bar or the Install app button.

**What should happen:** The app appears on the home screen or app list with the teal CELPIP icon and opens in its own window with no browser bar.

- [ ] iPhone Safari
- [ ] Android Chrome
- [ ] Desktop Chrome / Edge

**What should happen:** It opens. A small Offline label shows. Practice, Words and Grammar still work.

**How:** Android and desktop: long-press (or right-click) the app icon.

**What should happen:** You see three shortcuts: Practice, My plan, Timed Exam. Each opens the right screen. (iPhone does not show these; that is normal.)

## 7. Camera QR transfer between two devices

**How:** Device A: Settings, Send by QR. Device B: Settings, Receive by QR, Open camera, point at A. Try both ways between phone and computer.

**What should happen:** B asks for camera permission only after you tap Open camera. The counter climbs to all codes received. Add as new profile works and shows the data. The camera light goes off afterwards.

- [ ] iPhone Safari
- [ ] Android Chrome
- [ ] Desktop Chrome / Edge

## 8. Share-sheet file

**How:** Settings, Send backup to another device. Pick Messages, Mail, Files or a nearby device.

**What should happen:** The system share sheet opens with a .json backup. If the browser cannot share files, the backup downloads instead and a message says so. Importing it on the other device works.

- [ ] iPhone Safari
- [ ] Android Chrome
- [ ] Desktop Chrome / Edge

**What should happen:** A short buzz on each tap, and no buzz with reduced motion on or the switch off. iPhone does not vibrate; that is normal.
